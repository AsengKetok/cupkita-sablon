Fitur
- 4 halaman: Beranda, Tentang Kami, Produk, Kontak
- Navbar dengan sub menu dropdown (muncul saat hover) pada Tentang Kami dan Produk
- Hamburger menu pada tampilan mobile
- Desain playful: cup mengambang, blob gradasi, marquee berjalan, dan stiker berputar
- Animasi CSS: hover kartu, tombol shine, highlight marker, orbit, dan sparkle
- Scroll reveal bertahap, angka statistik berjalan, progress bar, dan tombol kembali ke atas
- Confetti kecil saat formulir kontak berhasil dikirim (simulasi)
- Menghormati prefers-reduced-motion untuk pengguna yangtidak suka animasi
- Responsif untuk desktop dan mobile
- HTML, CSS murni, dan JavaScript
